CHRONNUS — ATUALIZAÇÃO DO PROJETO

O que foi atualizado
- Cards de categorias com descrição e guia rápido para Máquinas, Periféricos e Variados.
- Seções de produtos na ordem Máquinas, Periféricos e Variados.
- Fallback de imagens e normalização de caminhos com barra invertida para evitar falhas em ambientes diferentes.
- Carrinho por sessão: adicionar produtos, atualizar quantidades, remover itens e finalizar um pedido com vários produtos.
- Atalho e quantidade do carrinho no menu; resumo do carrinho também aparece na página de informações do usuário.
- Botão Sair removido do cabeçalho da loja e colocado ao lado de Excluir minha conta na área da conta.
- Botão Ver ofertas removido do cabeçalho; a barra de busca ganhou mais espaço.
- O login agora aceita retorno seguro para carrinho.php.
- Os dois arquivos SQL foram reunidos em sql/chronus.sql.

Carrinho
O carrinho desta versão usa a sessão PHP do navegador. Os itens permanecem enquanto a sessão estiver ativa; ao encerrar/expirar a sessão, o carrinho pode ser perdido. O checkout cria um pedido pendente com todos os itens e recalcula os preços no servidor. O sistema não processa pagamentos.

Banco de dados
sql/chronus.sql agora reúne o conteúdo dos dois SQL anteriores. Atenção: o script original de instalação contém DROP TABLE IF EXISTS e recria tabelas. Execute-o somente para instalar/recriar o banco em ambiente vazio ou depois de fazer backup; não o reimporte em uma base que contenha dados que você deseja preservar.

Configuração
Confira usuário, senha, host e nome do banco em config/conexao.php.

Validação realizada
Todos os arquivos PHP passaram pela verificação de sintaxe (php -l). A integração com MySQL não foi executada neste ambiente, pois não há um servidor MySQL disponível para testar a conexão e os pedidos ponta a ponta.


ATUALIZAÇÃO COMPLEMENTAR — CATEGORIA VARIADOS E OFERTAS
- A categoria VARIADOS é garantida automaticamente e recebe produtos de tecnologia como mouse pad, power bank, carregador sem fio, luminária LED e organizador de cabos.
- Os novos produtos possuem ilustrações SVG próprias na pasta imgs/.
- A opção Ofertas do cabeçalho abre uma página de listagem apenas com produtos cujo desconto é maior que zero.
- O link Início foi removido do menu; a logo continua levando ao topo da loja.
- Os botões de adicionar ao carrinho agora mostram somente o ícone imgs/shopping-cart.svg.

- Os registros padrão de VARIADOS são criados/atualizados automaticamente ao abrir index.php, desde que exista o vendedor de catálogo catalogo@chronnus.local no banco.
